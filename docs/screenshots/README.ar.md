# معرض الواجهات

هذا المستند جولة بصرية على كل شاشة في Flavor، مأخوذة من نسخة تعمل فعلياً ومزروعة بالبيانات التجريبية الموصوفة في [الـ README الجذري](../../README.ar.md). وهو مستند مرجعي فقط: لا شيء هنا يغيّر التطبيق أو يحل محله، وتبقى الواجهة الفعلية المرجع الوحيد الموثوق إذا اختلفت شاشة عن وصفها مستقبلاً.

الشاشات مجمّعة تماماً كما يجمّعها التطبيق نفسه: الموقع العام، تسجيل الدخول، حساب الزبون، ومساحة عمل الموظفين — وهذه الأخيرة مقسّمة بحسب المنصب الذي سُجّل الدخول به عند كل التقاط، لأن الشريط الجانبي والصلاحيات خلفه يتغيران حسب الدور. هذا التقسيم يطابق جدول [الأدوار والصلاحيات](../../README.ar.md#الأدوار-والصلاحيات) في الـ README الجذري.

## كيفية قراءة هذا المعرض

كل صورة موجودة تحت `docs/screenshots/<القسم>/`، ومرقّمة بالترتيب الذي يتنقّل فيه شخص طبيعياً داخل ذلك القسم. الأقسام الثلاثة الخاصة بالموظفين تستخدم بالضبط الحسابات التجريبية الموثقة في جدول [الحسابات التجريبية](../../README.ar.md#الحسابات-التجريبية) بالـ README الجذري:

| القسم | تسجيل الدخول باسم | المنصب | الصلاحيات |
| --- | --- | --- | --- |
| مساحة عمل الموظفين — المدير | رانيا حداد | مدير | catalog وinventory وfloor وsales وpeople وreports |
| مساحة عمل الموظفين — الشيف | سامر خوري | شيف | catalog وinventory |
| مساحة عمل الموظفين — النادل | نور عباس | نادل | floor وsales |

لذلك يعرض قسما الشيف والنادل شريطاً جانبياً ولوحة تحكم أصغر فعلياً، لا نسخة مبتورة من شاشة المدير — فمساحة العمل لا تعرض إلا الأقسام التي يستطيع المنصب المسجّل دخوله الوصول إليها، كما هو موضح في [الأدوار والصلاحيات](../../README.ar.md#الأدوار-والصلاحيات).

عدد من صفحات الموقع العام التُقطت مرة لكل لغة واجهة (الإنجليزية والفرنسية والعربية) ومرة لكل مظهر (فاتح وداكن)، لتوضيح قسمي [اللغات](../../README.ar.md#اللغات) و[الهوية ونظام التصميم](../../README.ar.md#الهوية-ونظام-التصميم) في الـ README الجذري. أما بقية الشاشات فمُلتقطة بالإنجليزية والمظهر الفاتح، لأن كل مكوّن يُعرض بالشكل نفسه تماماً بعد الترجمة أو التبديل إلى المظهر الداكن.

الأرقام المرجعية للطلبات وأسماء الزبائن والمجاميع والتواريخ الظاهرة في هذه اللقطات جزء من البيانات التجريبية المزروعة، وستختلف بعد تنفيذ `php artisan migrate --seed` من جديد.
