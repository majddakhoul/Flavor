The staff workspace, split by position. A Manager can reach every use case on this page; other positions see only what their ability set unlocks, in both the web sidebar and the API.

Actor Use case (Flavor capability)
Where each use case lives in the code
  • Every box here is gated by an ability (catalog, inventory, floor, sales, people, reports) checked by the ability:* middleware on both the web and API route groups — see the Roles & Abilities table in the main README.
  • A Manager holds every ability by definition (EmployeePosition::Manager->abilities()); the other rows show exactly the subset each position holds today.
  • Review most-consumed ingredients and most-consumed / top-selling figures are new reporting endpoints added in this rebuild (IngredientRepository::mostConsumed(), MealRepository::topSelling(), OfferRepository::topSelling()).
  • Read staff notifications covers the two staff-only alerts this rebuild introduced: a new order and a new reservation, both pushed the moment they are created.
