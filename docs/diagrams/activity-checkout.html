Checkout — from Cart to Confirmed Order

← Back to README

The most business-critical path in the system: turning a cart into a paid order without ever overselling stock, even under concurrent checkouts.

Swimlane (actor / layer) Decision Note
Maps to
  • App\Services\Sales\CartService, CheckoutService::place(), OrderService.
  • Stock locking: IngredientRepository::lockMany() with lockForUpdate() inside the transaction, so two simultaneous checkouts for the last portion cannot both succeed.
  • App\Events\OrderPlaced → SendOrderConfirmation (customer, mail+database) and NotifyStaffOfNewOrder (staff with the sales ability, database only).
  • API: POST /account/checkout. Cancelling later (see the Order state chart) restores exactly the stock this flow consumed.
