Order Status Update

← Back to README

A staff member moves an order forward (or cancels it). Every transition is validated against the enum before anything is written, then the customer is told immediately.

Component Active call (activation bar)
Maps to
  • OrderService::transition(), guarded by App\Enums\OrderStatus::allows() — see the Order state chart for the full transition map.
  • App\Events\OrderStatusChanged → SendOrderStatusUpdate → App\Notifications\Sales\OrderStatusUpdated, which reuses OrderStatusMail for the email half and writes its own database row for the bell.
  • Cancelling here (not shown) additionally restores the stock consumed at checkout, inside the same transaction.
