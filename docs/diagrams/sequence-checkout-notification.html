What happens after the database commit: one event, two independent listeners, two different channel choices — this is the shape every domain event in Flavor follows.

Component Active call (activation bar)
Maps to
  • App\Events\OrderPlaced, registered listeners in EventServiceProvider: SendOrderConfirmation, NotifyStaffOfNewOrder.
  • Both listeners implement ShouldQueue — they run on the mail queue after the HTTP response has already been sent, so a slow mail server never delays checkout.
  • See docs/NOTIFICATIONS.md for why the customer gets mail+database and staff get database-only.
