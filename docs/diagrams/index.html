Flavor — Architecture & Behaviour Diagrams

← Back to README

Twelve diagrams covering every UML view named in the project brief — class, object, state chart, use case, activity and sequence — for the system's core scenarios: registration, checkout, reservations, order status, and authentication. Every diagram is plain, hand-authored SVG in a static HTML page, styled with the same colour tokens as the application itself, so nothing here needs a diagramming tool to open, edit or keep in sync with the code — open any page in a browser or a text editor.
