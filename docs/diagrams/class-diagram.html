Reading this diagram
  • Every association shown here is implemented as an Eloquent relationship in app/Models/*.php — this diagram is generated to match the code, not the other way around.
  • Pivot tables (ingredient_meal, meal_order, offer_order, meal_offer, reservation_table) carry their own columns (quantity, notes, start/end time) and are noted on the connecting edge rather than drawn as separate boxes, to keep the diagram legible.
  • Translation is a single polymorphic table (translatable_type / translatable_id) shared by every model using the HasTranslations trait — Category, Meal, Ingredient, Offer and Table — rather than one table per entity.
  • Enum-typed attributes (UserType, OrderStatus, ReservationStatus, EmployeePosition, ...) are detailed on their own state charts where relevant — see the State Charts section.
